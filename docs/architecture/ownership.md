# Ownership

| Area | Review owner |
|---|---|
| `apps/web`, `packages/contracts` | web |
| `internal/access` | access/security |
| `internal/recordings` | recordings/connectors |
| `internal/library` | library/product |
| `internal/runtime` | runtime/reliability |
| `internal/delivery` | delivery/integrations |
| `internal/adapters`, `internal/platform` | platform plus the affected domain owner |
| `protocols` | runtime plus every consuming owner |
| `services/speech` | speech/ML |
| `deploy` | platform/SRE |

Names are role owners until repository teams are configured. CODEOWNERS uses the repository owner as the enforceable fallback.
